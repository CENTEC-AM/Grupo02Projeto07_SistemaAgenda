# GRUPO 02 - PROJETO 07
# AGENDA DE CONTATOS

Projeto desenvolvido para a disciplina de Técnicas de Programação para a Internet com o objetivo de criar uma agenda de contatos completa, com funcionalidades de cadastro, pesquisa, edição, exclusão e ordenação, utilizando persistência de dados do navegador (Local Storage).

## Funcionalidades

- Cadastro de contatos com nome, sobrenome, empresa, telefone e observações.
- Listagem de todos os contatos cadastrados.
- Pesquisa dinâmica por nome, empresa ou telefone.
- Edição de contatos existentes.
- Exclusão de contatos com confirmação.
- Ordenação por nome, empresa ou telefone.
- Persistência dos dados no Local Storage do navegador.
